# ZEXOR — Standalone Redesign

Separate React + Vite + TypeScript frontend concept.

## Run
```bash
npm install
npm run dev
npm run build
```

Includes responsive Arabic/English RTL/LTR UI, six brand worlds, animated abstract brand mark and editorial product layout. This is a frontend scaffold only: it is not connected to production Supabase/database, authentication, orders, checkout/payment, permissions or admin. Integrate and test those real systems before launch; do not replace them with mock functionality.
